# Ornamen Dekorasi — "Punakawan Vintage"

Aset dekorasi/ornamen bergaya vintage untuk undangan digital. Diunduh dari situs
rujukan **punakawandigital.id** (domain aset: `inv.punakawandigital.id`) pada
2025-09-30, melalui halaman contoh tema **Premium Vintage 01**:
<https://inv.punakawandigital.id/vintage-01/>

Folder ini **hanya berisi ornamen/dekorasi** (tekstur bunga, bingkai, divider).
Tidak ada foto orang, logo brand, atau aset pembayaran/kartu yang disertakan.
